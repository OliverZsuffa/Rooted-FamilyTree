# Request 007: Family-centred automatic layout

## Goal

Correct the automatic tree layout so that children are positioned as a sibling group centred beneath their recorded parent or parents. In a two-parent family, the centre of the children should align with the midpoint between the two parents.

## Confirmed requirements

- Keep children who share a recorded biological or adoptive parent adjacent as a sibling cluster.
- Centre each sibling cluster beneath the average horizontal position of its recorded parents.
- Keep generations on separate horizontal bands.
- Keep cards readable with consistent horizontal spacing and no overlaps.
- Preserve each person as one unique card. Never duplicate a person to represent multiple partnerships.
- Keep distinct parent sets and their family junctions distinct. A partnership alone must never create parentage.
- Balance ordering when a parent has children with multiple partners. Children sharing that parent remain adjacent, while distinct recorded parent sets retain distinct junctions.
- Preserve manual dragging and saved manual positions. Automatic layout must not overwrite manual positions.
- Retain the working incompleteness and dark mode features without modifying them.

## Scope exclusions

No redesign of cards, relationship editing, incompleteness indicators, theme styling, persistence format, or manual positioning controls.
