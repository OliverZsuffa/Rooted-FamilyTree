# Request 015: Global parentage based ordering

Develop and select a global ordering method for the complete recorded parentage graph, then use it to make complex family branches readable across generations. The method must preserve exact parent-set sibling groups and shared people without duplicating them.

See [implementation-plan.md](implementation-plan.md) for the research, prototype, selection criteria, implementation scope, and acceptance criteria.

## Status

Planning only. No application code has been changed. The next step is to compare candidate algorithms in a controlled prototype. Application implementation requires explicit user approval after that comparison and a revised final implementation proposal.
